# Digital Studio Website | Kyle Wessels

> **Digital experiences designed around your business.**

A modern, responsive business website for a digital design and development studio focused on helping businesses build better digital experiences.

The project is being developed with a focus on **design, usability, accessibility, performance, maintainability, and future scalability**.

---

## Project Status

**Status:** 🚧 In Development

The project is currently in the **foundation and design phase**.

The brand name and visual identity are still being explored. Current naming concepts include:

* Digital by Design
* Human Digital
* Built Digital
* Digital Built
* Digital Design Studio

The final business name will be selected after further brand, market, SEO, domain, and trademark research.

---

## Vision

The goal is to create more than a conventional business website.

The website itself should demonstrate the qualities we offer clients:

* thoughtful design
* clear communication
* technical competence
* accessibility
* responsive experiences
* performance
* maintainable code
* attention to detail

A visitor should feel:

> **Welcome → Understood → Confident → Ready to Engage**

The experience should invite visitors to explore and ask questions rather than pressure them into making a decision.

---

## Core Philosophy

### Experience First

A website should feel like an experience, not simply a digital brochure.

### Business First

Technology should support the business rather than become the centre of the conversation.

### Human First

Digital experiences should be understandable, accessible, and enjoyable for the people using them.

### Evidence Over Claims

The website should demonstrate capability through:

* real work
* clear processes
* thoughtful design
* technical implementation
* measurable outcomes where available

### Progressive Disclosure

The primary experience should communicate value and outcomes first.

Technical details can be progressively introduced for visitors who want to understand how the work is built.

## Brand Direction

The intended personality combines:

* **Trusted**
* **Professional**
* **Approachable**
* **Premium**
* **Refined**
* **Modern**
* **Technically competent**

The visual direction is inspired by luxury through **simplicity rather than decoration**.

This means:

* generous whitespace
* strong typography
* restrained colour
* precise spacing
* high-quality visual elements
* subtle motion
* minimal clutter
* clear hierarchy

The design should feel premium without becoming flashy or intimidating.

## Technology

### Current Development Stack

The initial implementation is intentionally simple:

* HTML5
* Tailwind CSS

A production build process will be introduced when the project moves beyond prototyping.

### Potential Future Stack

As requirements justify additional complexity, the project may evolve toward:

* Next.js
* TypeScript
* Tailwind CSS
* PostgreSQL
* Prisma
* Python services where appropriate
* Azure
* GitHub
* CI/CD
* Monitoring and observability

Technology decisions will be driven by requirements rather than introduced prematurely.

## Frontend Principles

The frontend should:

* use semantic HTML
* be responsive
* support keyboard navigation
* maintain accessible colour and contrast
* provide meaningful document structure
* minimize layout instability
* progressively enhance functionality
* remain maintainable
* perform well on mobile devices

The goal is not simply to make the website look good.

The implementation should demonstrate **good engineering through the experience itself**.

## Accessibility

Accessibility is treated as a fundamental design requirement rather than a final checklist.

The project will consider:

* semantic HTML
* heading hierarchy
* accessible navigation
* keyboard interaction
* focus states
* descriptive link text
* appropriate image alternatives
* reduced-motion preferences
* colour contrast
* responsive text and layouts

## Responsive Design

The website is designed mobile-first.

### Desktop

The primary layout uses:

```text
Brand        Navigation        Primary CTA
```

The hero uses a two-column structure:

```text
┌─────────────────────────────┬──────────────────────┐
│                             │                      │
│   Value Proposition         │                      │
│                             │     Visual /         │
│   Supporting Content        │     Experience      │
│                             │                      │
│   Primary CTA               │                      │
│   Secondary CTA             │                      │
│                             │                      │
└─────────────────────────────┴──────────────────────┘
```

### Mobile

The navigation collapses and the hero becomes a single-column experience.

```text
Brand                         Menu
────────────────────────────────────

Eyebrow

Main Heading

Supporting Content

Primary CTA
Secondary CTA

Visual
```

